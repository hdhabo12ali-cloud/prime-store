API والبوت

اربط بوت الديسكورد أو أي أداة خارجية بموقعك عبر مفاتيح API.

نقاط الوصول (Endpoints)

أرسل الطلبات مع الهيدر x-api-key يحمل قيمة المفتاح.

GET/api/bot/catalogكل الباكجات والمنتجات
GET/api/bot/settingsاسم الموقع + رابط الديسكورد

مفاتيح API

أنشئ مفتاحًا مستقلًا لكل بوت أو تكامل، وألغِ أي مفتاح مسرّب فورًا.
